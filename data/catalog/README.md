# Versioned catalogues and discovery records

The committed JSON records retain the initial npm catalogue and company-discovery
follow-up evidence. Identities, effective mappings, provenance and unresolved
questions belong to the versioned record; a discovery entry alone does not
establish a verified model-training label.

Collection recipes live in `configs/data`. Source and catalogue contracts are
implemented in `oxhack2026/catalog`, with schemas under `contracts/datasets/data`.
Use the [product definitions](../../PLAN.md) and
[public-cohort notes](../../docs/tasks/dev1/D1-O4-public-cohort-discovery.md) when
extending a cohort. Generated observations remain outside version control.
