# D1-O1: company source contracts and local reader

`catalog.company` provides the additive `company-source-v1` source records.
`storage.company.CompanySourceReader` is the consumer interface;
`LocalCompanyStore` implements it with content-addressed bytes and atomic CAS.
Raw source artifacts must already exist in the store before publication.

```python
from pathlib import Path
from oxhack2026.storage.company import LocalCompanyStore

store = LocalCompanyStore(Path("artifacts/company-evidence"))
publications = store.snapshots()
snapshot = store.snapshot("explicit-published-id")
companies = store.companies(snapshot.snapshot_id)
coverage = store.coverage(snapshot.snapshot_id, companies[0].company_id)
family = store.family_at(snapshot.snapshot_id, companies[0].company_id, snapshot.as_of)
```

No vendor calls, latest-version substitution, model policy or API implementation
occur in reads. Construction performs no I/O. Unknown IDs raise KeyError;
corruption/invalid records raise ValueError; filesystem failures raise OSError.

Each snapshot stores normalized company, relationship, definition, evidence,
metric and event tables in one hash-pinned JSON payload. Its manifest repeats and
verifies the immutable metadata. Raw evidence bytes are verified on publication
and reads. The reader can be replaced by a database implementation without
changing consumer contracts. No database deployment is claimed here.

Every company/metric definition requires exactly one selected observation,
including explicit missing/inapplicable/conflicting rows. This makes the coverage
denominator inspectable. One metric definition selects one period in a snapshot;
use distinct versioned definitions for different periods (e.g. 30 and 90 days).
Coverage is derived from frozen tables and the snapshot cutoff, not the wall
clock. Freshness uses the measurement boundary, so re-fetching old observations
does not make them current. Numeric values use discriminated strict integer,
exact decimal and Boolean variants; monetary definitions carry their currency.

Source evidence is company-scoped. Cross-company evidence, unsupported observed
values, mismatched types, duplicate selected vintages and future source facts are
rejected. Historical reconstruction is the only mode permitting later-collected
bytes, and retains their actual collection times. Family membership uses explicit
`subject_kind="family"` relationships, with evidence available at the requested
cutoff; absence/conflict returns a nullable family and reason codes. No implicit
self-family or current-parent backdating is applied.

Event dates currently support exact calendar day or unknown, not fabricated
subday precision. Announcement/completion/reporting and company shutdown/product
retirement remain distinct. Restricted source attachments never have public URLs;
Dev 3 must strip internal artifact references and restricted evidence in public
projections. Verification status is about source assertions, not company success.

Schemas are generated by `python -m oxhack2026.storage.export_contracts`.
Saved `tests/fixtures/data/company-source*.json` are explicitly synthetic.
Tests cover contract integrity, frozen readers, zero/missing/stale states, family
cutoffs/conflicts, immutable IDs, interrupted publication, concurrent CAS and raw
corruption. These are software checks, not predictive validation or a real handoff.
