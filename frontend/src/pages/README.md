# Product views

The directories here reserve the five views in `PLAN.md`, section 2.4. No routes,
page components, data fetching, or application state are implemented.

- `rankings/`: the research shortlist and baseline comparisons.
- `tool-detail/`: observed history, aggregate forecasts, and evidence.
- `replay/`: historical forecast selection and future reveal.
- `evaluation/`: experiment reports and model comparisons.
- `data-health/`: source coverage, freshness, and failures.
