# Product views

Company outlook is the primary workflow in `PLAN.md`:

- `companies/`: explicit publication selection, searchable/filterable company
  table, three-outcome profiles, source inspection and up-to-three comparison.
- `methodology/`: outcome meanings, evidence states and probability release rules.

The retained traction workflow uses separate routes and API contracts:

- `rankings/`: the research shortlist and baseline comparisons.
- `tool-detail/`: observed history, aggregate forecasts, and evidence.
- `replay/`: historical forecast selection and future reveal.
- `evaluation/`: experiment reports and model comparisons.
- `data-health/`: source coverage, freshness, and failures.
