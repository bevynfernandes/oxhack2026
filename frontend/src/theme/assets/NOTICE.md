# Theme assets

- `barlow-condensed-latin-600.woff2`: Barlow Condensed, semibold, Latin subset,
  Google Fonts release v13. Copyright 2017 The Barlow Project Authors
  (https://github.com/jpt/barlow). SIL Open Font License 1.1; see OFL.txt.
  Retrieved 2026-10-24 from
  https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B4873z3bWuQ.woff2
  through https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@600&display=swap.
  Served locally; no Google Fonts request occurs in the application.

- `barlow-condensed-latin-200.woff2`: Barlow Condensed, extra light, Latin subset,
  Google Fonts v13, same SIL OFL licence as the semibold face. Retrieved 2026-10-24
  from https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B497yz3bWuYMBYro.woff2.
- `armillary.svg`: original vector construction of an armillary sphere, etched
  meridians, orbital rings and pedestal, created for SignalShift. Decorative only;
  it does not represent data or use Hermes artwork.
- `grain.svg`: original small, static SVG noise tile. No JavaScript or animation.
- `laurels.svg`: original repeating line-art pattern of trophies, medals and
  laurels created for SignalShift. Decorative only; it contains no copied
  artwork, branding or factual content. Its orange and white treatment uses
  SignalShift's HRT-inspired theme palette without reproducing HRT artwork.
- `rocket-line-drawing.svg`: Rocket Line Drawing from SVG Repo, licensed CC0.
  Retrieved 2026-10-25 from
  https://www.svgrepo.com/svg/480695/rocket-line-drawing. Decorative only.
